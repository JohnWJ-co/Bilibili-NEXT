# 目标

macOS 侧栏折叠改由点击顶部 logo 完成：去掉侧栏顶部的设置图标和独立的折叠按钮图标，logo 同时承担展开/折叠切换，从而让折叠后的侧栏宽度比现在的 88pt 更窄。

# 范围

本轮只调整 `RootView` 侧栏头部、折叠宽度和折叠态（图标轨）的排版尺寸；不改导航行为、账号功能、未读计数来源和展开态的菜单/入口。

## 目录结构

### 新建

无

### 修改

- Sources/BiliGlass/Views.swift — `RootView.sidebar(compact:collapsed:)` 头部：移除 `SettingsLink`（第 169 行）和 `sidebarToggle`（第 173 行）两个控件，logo 图标改为切换按钮并沿用 ⌥⌘S 快捷键与“收起侧栏/展开侧栏”提示；`navigationRail`/`accountRail` 的图标与内边距按更窄宽度重新取值。
- Sources/BiliGlass/GlassStyle.swift — `AppLayout.sidebarRailWidth` 从 88 降为 56（`sidebarWidth` 224 不变）。

### 删除

- Sources/BiliGlass/Views.swift 的 `sidebarToggle` 计算属性（上一轮 `sidebar-collapse` 实现新增的独立折叠按钮）— 功能由 logo 按钮承担，⌥⌘S 快捷键随按钮迁移。

### 明确不建

- 新的设置入口或侧栏底部设置行 — 顶部栏齿轮（Views.swift:323）、账号菜单“设置”（Views.swift:247、372）、下载页与空间页的设置按钮和 ⌘, 已覆盖。
- 侧栏宽度设置项或拖拽调宽 — 折叠宽度用 `AppLayout` 常量即可，配置项会扩大范围。
- 悬停浮出展开的自动折叠逻辑 — 用户只要求点击 logo 切换。

# 非目标

- 不改 iPad/iOS 侧栏（`Apps/iOS/Sources/MobileTablet.swift` 已有自己的收起方式）。
- 不改展开态的分组标题、账号名称显示、未读计数与下载计数的取数逻辑。
- 不改主题、玻璃材质、背景和其他页面布局。
- 不发版：不改 `CHANGELOG.md`、`GuideContent.currentUpdates` 和 bundle 版本号。

# 验收示例

- A1：展开态侧栏顶部只有粉色 logo 和“Bilibili NEXT”文字，设置（滑块）图标和独立折叠按钮图标都不再出现。
- A2：展开态点击 logo，侧栏在 224pt 动画收窄为 56pt 的图标轨；折叠态再次点击 logo（顶部卡片里的 logo）恢复 224pt 展开态。
- A3：折叠态只显示 11 个导航图标（推荐、热门、分区、关注动态、消息 + 观看记录、收藏、稍后再看、下载、我的主页、更多），图标完整不裁切、不重叠、不显示文字；当前页仍有粉色高亮。
- A4：折叠态下消息未读或下载进行中仍显示提示点，鼠标悬停图标仍显示对应名称（如“消息”）。
- A5：折叠态点击账号头像仍能打开“我的主页 / 设置 / 重新登录 / 退出登录”菜单；未登录时显示登录图标且点击可发起登录；恢复登录中显示小号进度圈。
- A6：折叠态与展开态都保留键盘切换 ⌥⌘S，VoiceOver 读到“收起侧栏/展开侧栏”，且删除侧栏设置图标后设置窗口仍可从顶部栏齿轮、账号菜单或 ⌘, 打开。
- A7：折叠状态重启应用后保持；窗口为最小尺寸 1020×700 时折叠态布局不错位、图标轨不出现横向裁切。

# 关键决定

- 折叠宽度取 56pt：图标 20pt 加左右 10pt 内边距仍留有可点区域，比现值 88pt 明显更窄，也够放未读提示点。
- logo 按钮承担折叠切换后，⌥⌘S 快捷键跟着 logo 走，不额外新增菜单项。
- 折叠态顶部卡片整块可点（`contentShape`），避免 56pt 宽度下只有一个 20pt 小的命中区。
