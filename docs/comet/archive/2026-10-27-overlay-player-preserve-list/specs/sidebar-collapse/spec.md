# sidebar-collapse 规格（macOS 侧栏折叠）

描述 macOS 应用主窗口左侧导航侧栏的折叠行为，包含折叠入口、折叠态内容、宽度与状态持久化。

## Requirements

### Requirement: 侧栏折叠入口

折叠与展开由侧栏顶部的 logo 提供：logo 是可点击控件，点击一次在展开态与折叠态之间切换；侧栏顶部不显示独立的折叠按钮图标，也不显示设置图标。系统设置仍可从顶部栏齿轮、账号菜单或 ⌘, 打开。

#### Scenario: 展开态点击 logo 折叠

- **WHEN** 侧栏处于展开态，用户点击侧栏顶部的 logo
- **THEN** 侧栏切换为折叠态，宽度由 224pt 变为 56pt
- **AND** 侧栏顶部不再出现设置图标或独立的折叠按钮图标
验收：A1

#### Scenario: 折叠态点击 logo 展开

- **WHEN** 侧栏处于折叠态，用户点击折叠卡片中的 logo
- **THEN** 侧栏恢复展开态，宽度回到 224pt，并重新显示“Bilibili NEXT”标题文字
验收：A2

#### Scenario: 键盘与无障碍入口

- **WHEN** 主窗口获得焦点，用户按下 ⌥⌘S
- **THEN** 侧栏在展开与折叠之间切换
- **AND** 该入口在 VoiceOver 中读作“收起侧栏”或“展开侧栏”，与当前状态一致
验收：A6

### Requirement: 折叠态图标轨内容

折叠态只保留图标：全部 11 个导航入口以图标形式纵向排列，分属“浏览”和“资料库”两张玻璃卡片，不显示分组标题与入口文字；当前页图标保留粉色选中底色。

#### Scenario: 折叠态显示全部导航图标

- **WHEN** 侧栏处于折叠态
- **THEN** 依次显示推荐、热门、分区、关注动态、消息、观看记录、收藏、稍后再看、下载、我的主页、更多共 11 个图标
- **AND** 图标完整可见、不裁切、不重叠，且不显示任何文字标签
- **AND** 当前页面图标仍有粉色选中底色
验收：A3

#### Scenario: 折叠态保留提示与悬停说明

- **WHEN** 侧栏处于折叠态且存在未读消息或进行中的下载
- **THEN** 对应图标仍显示提示点
- **AND** 鼠标悬停在该图标上时显示对应入口名称（如“消息”）
验收：A4

### Requirement: 折叠态账号入口

折叠态底部账号卡片只显示一个居中的账号图标，并保持展开态账号操作的全部能力。

#### Scenario: 折叠态打开账号菜单

- **WHEN** 侧栏处于折叠态且已登录，用户点击账号头像
- **THEN** 打开包含“我的主页 / 设置 / 重新登录 / 退出登录”的菜单
验收：A5

#### Scenario: 折叠态未登录或恢复中

- **WHEN** 侧栏处于折叠态且未登录
- **THEN** 显示登录图标，点击可发起登录
- **AND** 本机登录恢复过程中显示小号进度圈，不显示登录入口
验收：A5

### Requirement: 折叠状态持久化与窄窗口表现

折叠状态跨启动保存，并且在窗口最小尺寸下仍保持可用布局；折叠宽度切换的动画遵循“界面动画”设置与系统减少动态效果。

#### Scenario: 重启后保持折叠状态

- **WHEN** 用户在折叠态退出应用后重新启动
- **THEN** 侧栏仍以折叠态显示
- **AND** 当系统开启“减少动态效果”或应用关闭“界面动画”时，宽度切换不带动画
验收：A7

#### Scenario: 最小窗口尺寸下的折叠态

- **WHEN** 窗口处于最小尺寸 1020×700 且侧栏折叠
- **THEN** 图标轨与账号卡片完整显示，无横向裁切、无控件重叠，内容区获得更宽的可用空间
验收：A7
